Save Tawasol Logo

Instructions:

Step 1: Right-click on the logo image you uploaded in the chat
Step 2: Select "Save image as..."
Step 3: Navigate to:
c:\Projects\tawasol-crm\frontend\public\
Step 4: Save the file as: logo.png
Step 5: Refresh your browser at http://localhost:5173

Alternative: You can also drag and drop the image file directly into the public folder in VS Code's file explorer.
